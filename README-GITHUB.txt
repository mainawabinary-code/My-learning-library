MY LEARNING LIBRARY — GITHUB PAGES

Files in this ZIP are intentionally at the ROOT:
  index.html
  manifest.json

GitHub Pages steps:
1. Create/open your GitHub repository.
2. Upload index.html and manifest.json directly into the repository root.
3. Commit the changes.
4. Go to Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”.
6. Select your main branch and “/ (root)”, then Save.
7. Wait for the Pages deployment to finish, then open the generated Pages URL.

Do NOT upload this ZIP as the deployed site. Extract it first, then upload the two files.
